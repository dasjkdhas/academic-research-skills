## 📦 上傳資料優先級

### 🔴 P0 — 立即解鎖更多分析

#### A) **電力資料：2025-04 → 2025-06 (前期前段)**
- **目前已有**: 2025-07-06 → 2025-10-31
- **缺**: 2025-04 (學期開始) 到 2025-07-05 (~3 個月)
- **解鎖**: 完整前期 (春學期) 資料 + 學期起始升載過程
- **檔案格式**: 同您給的 .xlsm 格式
- **預估**: 3 個 .xlsm 檔（April、May、June 各一）

#### B) **電力資料：2025-11 → 2026-02 (後期冬季)**
- **冬季供暖期** — 與夏季冷氣期形成對比
- **解鎖**:
  - 跨季模型驗證
  - CCRI 在不同季節的閾值穩定性
  - 創新點 2: Path A/B 是否會自動分出「夏季 vs 冬季」cluster
  - Heating-mode SDR 動作 (相對於 cooling-mode)
- **檔案格式**: 同 .xlsm
- **預估**: 4 個檔（每月一）

### 🟠 P1 — 補強現有分析的可信度

#### C) **AMeDAS 宇部站實測氣象**
- 目前用 ERA5 reanalysis (Open-Meteo)，是 0.25° 網格內插
- 補實測 AMeDAS 讓論文可以說「reanalysis 與 field measurement 一致性 r=0.XX，無顯著系統性偏差」
- **下載方式**: 
  - 訪問 https://www.data.jma.go.jp/risk/obsdl/index.php
  - 選「都道府県」→「山口」→ 選「宇部」站
  - 期間：2025-04 → 2026-02
  - 項目：氣温、湿度、降水量、風向風速、日照時間、現地気圧
  - 時間單位：1 小時
  - 輸出 CSV
- **預估**: 1 個 CSV (~5 MB)
- **解鎖**: 論文 Section 3.1 可以直接寫「ERA5 vs AMeDAS 對照」表 + Discussion 中關於 reanalysis 適用性的段落

#### D) **校歷補充：實際停課/補課/校慶日期**
- 目前用「標準學期 + 國定假日」，但可能漏掉：
  - 颱風停課 (山口縣常有)
  - 校慶/工學部祭
  - 期中考週 (中間試験)
  - 特別講座、學會主辦日
- **格式**: 簡單表格即可

```csv
date,event_type,description
2025-09-19,typhoon,Typhoon No.15 — campus closed
2025-10-25,festival,工学部祭 (1日)
2025-11-14,exam_midterm,中間試験開始日
...
```
- **解鎖**: Path A 人工標籤更精準 → 與 Path B clustering 對比更有信度

### 🟡 P2 — 解鎖進階分析（有就更好）

#### E) **空調 BEMS 紀錄** (如果學校有 BEMS 系統)
- 室內溫度設定點 / 實際溫度 / 室外機運轉 / 風量
- 解鎖: 創新點 4 升級 — 從「假設 12% 削減」變成「實測校準的削減係數」
- 格式: 時間序列 CSV / SQL dump
- 即使只有 1-2 棟也很有用

#### F) **學生人數 / 教職員人數動態**
- 如果學校有 ID 卡刷卡系統，每日各樓宇人流量
- 解鎖: 「樓宇佔用率 × 負荷」相關性分析，論文 Section 5 物理機制討論

#### G) **歷史 FRR 觸發紀錄**
- 過去校園實際被九州電力 FRR 通知/處罰的紀錄
- 解鎖: 把 CCRI Critical 預警與實際歷史告警**對標** — 這是論文最有力的驗證！
- 格式: 簡單時間清單即可

#### H) **天然瓦斯資料** (33b4b8b7-... 那個檔)
- 目前被跳過，但**冬季加上瓦斯 = 完整能源圖像**
- 解鎖: 「電力削峰是否導致瓦斯增量」交叉檢查 (對 Reviewer 質疑很重要)

## 🛠️ 資料上來後的執行流程

每次您新增資料，我會按以下順序執行：

### 階段 A: 增量診斷 (~20 min)

```
1. 將新檔案 append 進 campus_power_hourly.csv
2. 重新 run code/00c_diagnostic.py
3. 重新訓練 LightGBM + 全套 CCRI/SDR/SHAP
4. 自動產生 Δ-report: 與上次相比，哪些指標變了
```

### 階段 B: 解鎖性分析 (根據累積資料量自動觸發)

#### ✅ 累積 ≥ 6 個月：
- [ ] 啟用 **GRU Head B** (Focal Loss + dropout + LSTM 對照)
- [ ] **Bergmeir blocked CV**：5-fold blocked walk-forward
- [ ] **Diebold-Mariano test**：LightGBM vs GRU 顯著性
- [ ] **SDR 動作穩定性**: 各動作削減量在不同月份的變異係數

#### ✅ 累積 ≥ 12 個月：
- [ ] **跨季 CV**: 訓夏測冬、訓冬測夏，計算 transfer gap
- [ ] **絕對 CCRI 閾值**: 用 1800 kW (90% 容量) 替代百分位
- [ ] **Friedman + Nemenyi**: 多模型多季顯著性
- [ ] **Path A vs Path B 季節敏感性**: 是否在不同季節，clustering 表現差異
- [ ] **SDR 動作於冬季 (heating mode) 的適用性分析**

#### ✅ 補進 AMeDAS：
- [ ] **ERA5 vs AMeDAS 一致性檢驗**：r、RMSE、bias 表
- [ ] 重訓模型用 AMeDAS 取代 ERA5，看精度是否變化
- [ ] 寫進 Section 3.1 「Weather data validation」

#### ✅ 補進實際 FRR 紀錄：
- [ ] **CCRI Critical vs 實際 FRR 告警對標**
- [ ] 計算 Precision / Recall / Lead-time (告警提前量)
- [ ] 這是論文 Section 4.4 最有力的章節，**直接面對 Reviewer 質疑**

#### ✅ 補進 BEMS：
- [ ] **SDR 動作減量係數校準**：A/B 比較設定點變更前後
- [ ] 替換論文 Section 3.6 的 12%/18% 為實測值
- [ ] 升級 Innovation 4 為「實測校準」
