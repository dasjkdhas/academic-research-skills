# JFY2025 実証結果 — Track B 論文 Results ドラフト

**データ**: 山口大学キャンパス 全年小時電力 (JFY2025, 7,361 有効時間) + AMeDAS 宇部站気象 + 自動生成校歴 (週末 + 日本の祝日 + 季節)
**注**: 詳細学事日程 (上課/試験/休業/活動) は未入手。現状は「平日 vs 週末・祝日」の2分類で解析。学事日程入手後、RQ3 はさらに鋭くなる見込み。

## 0. 気象データ検証 (本論文の前提)

| 検証 | 結果 |
|---|---|
| ユーザー埋込 `気象庁データ` vs 自前スクレイプ AMeDAS | **完全一致** (mean 17.41 vs 17.42, 欠測数同一) → スクレイプ正確 |
| AMeDAS vs ERA5 — **気温** | 時 r=0.991 / 日 0.997 / 月 1.000 → **互換** |
| AMeDAS vs ERA5 — **降水** | 時 0.49 / 日 0.76 / 月 0.90 → 再解析の時刻ズレ、ERA5 誤りではない |
| AMeDAS vs ERA5 — **風速** | 時 0.66 / 日 0.74 → 許容 |

**結論**: ERA5 に誤りなし。降水の時別不一致は「再解析 vs 点観測」の既知のスケール効果。**論文主データは AMeDAS、ERA5 は気温の独立検証と欠測補完に使用**。

## 4.1 年間負荷プロファイルと制度パターン (RQ1)

| 指標 | 値 |
|---|---|
| 有効時間 | 7,361 h |
| 負荷レンジ | 428 – 1,794 kWh/h |
| 平均負荷 | 約 740 kWh/h |
| P80 / P95 | 後述 (容量リスク用) |

**季節平均負荷**: 夏 875 > 冬 763 > 秋 755 > 春 654 kWh/h
→ 夏のピークが最大だが、**冬も春・秋を上回る** (暖房需要の存在を示唆)。

**平日 vs 週末・祝日 (制度効果)**:
- 平日ベース負荷 ≈ 700 kWh/h
- 週末・祝日ベース負荷 ≈ 525 kWh/h
- **差 ≈ 175 kWh/h (約 25%) は純粋に制度的占用差** (気温と無関係)

→ RQ1 回答: 負荷は強い週周期 + 日内周期 + 季節周期を持ち、**制度状態だけで約 25% のベース差**を生む。

## 4.2 気温-負荷応答と季節閾値 (RQ2)

**日次エネルギー署名 (変点回帰, 全体)**:
| パラメータ | 値 |
|---|---|
| 暖房閾値 | 7.6 °C |
| 冷房閾値 | **17.2 °C** |
| 冷房感度 | **+24.6 kWh/h per °C** |
| 快適帯感度 | −14.9 kWh/h per °C |
| R² (日次, 全体) | **0.40** |

**重要な発見 (パラドックスではなく主張)**: 日次集計しても **R²=0.40** に留まる。
→ **気温だけでは負荷分散の半分以下しか説明できない**。残りは制度的占用 (曜日・時刻・学事) が共決定。
これは「キャンパス負荷は気温と制度日历の共同産物」という本論文の中心命題を実証。

## 4.3 校歴が調節する温度感度 (RQ3) ★ 核心結果

**校歴状態別 エネルギー署名**:

| 状態 | 冷房閾値 | 冷房感度 (kWh/h/°C) | R² | n (日) |
|---|---|---|---|---|
| **平日** | **17.6 °C** | 27.9 | 0.66 | 207 |
| **週末・祝日** | **22.6 °C** | 25.9 | 0.79 | 101 |

**2つの決定的発見**:

1. **冷房閾値が 5°C 異なる** (平日 17.6°C vs 週末 22.6°C)。
   → 同じ気温でも、平日は占用のため早く冷房応答が始まる。週末は建物が高温を許容してから応答。
   → **「制度日历が温度感度を調節する」= calendar-modulated temperature sensitivity を直接実証**。

2. **層別化で R² が劇的改善** (全体 0.40 → 平日 0.66 / 週末 0.79)。
   → 校歴状態は単なる制御変数ではなく、温度-負荷関係そのものを形作る**第一級の調節因子**。

これは既存文献 (校歴を予測特徴/占用代理として扱う) との明確な差別化点であり、本論文の novelty の実証的裏付け。

## 既知の限界と次のステップ

1. **学事日程未入手**: 現状「平日」には夏季休業中の平日も混入 → 効果が希釈されている。
   実際の「上課日 / 試験期 / 休業 / 活動日」が入れば、RQ3 のコントラストはさらに拡大する見込み。
2. **暖房側の不安定**: 寒冷端の平日データが少なく (冬季キャンパス占用低)、暖房感度の推定が不安定。
   寒冷端アーティファクト (図H の赤線急上昇) はサンプル希薄が原因。
3. **2026-01/02 の電力欠測**: 真冬のサンプルが少ない → 暖房応答の確証には追加データが望ましい。
4. **次**: 契約容量を入手次第、RQ4 (容量リスク = 負荷/容量 の温度×校歴空間での集中) を実装。
